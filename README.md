Pastella adalah aplikasi katalog belanja Flutter dengan tampilan pastel dan data
produk dari [DummyJSON](https://dummyjson.com/).

## Fitur

- Jelajahi produk dan filter berdasarkan kategori.
- Urutkan produk berdasarkan rating, harga, atau nama.
- Cari berdasarkan nama produk, merek, atau kategori.
- Lihat detail produk, rating, merek, deskripsi, dan stok.
- Simpan produk favorit.
- Tambahkan produk ke keranjang, ubah jumlah, dan lihat total belanja.
- Jelajahi miniatur tank baja koleksi bergaya mainan.
- Checkout demo dengan validasi alamat, pilihan pengiriman dan metode pembayaran,
  ringkasan total, serta konfirmasi pesanan.

Favorit dan isi keranjang disimpan sementara selama aplikasi berjalan. Harga
mengikuti mata uang yang disediakan API. Checkout hanya simulasi dan belum
mengirim pembayaran atau pesanan ke layanan eksternal.

## Menjalankan aplikasi

```bash
flutter pub get
flutter run
```

Jalankan pengujian dan analisis kode dengan:

```bash
flutter test
flutter analyze
```
